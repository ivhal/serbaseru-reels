# Stok video Reels Serba Seru

Dibaca oleh app **Stok Reels** (Android). App memuat `manifest.json` dari GitHub Pages, sehingga video baru langsung muncul tanpa memperbarui app.

- `manifest.json`: daftar video (judul, deskripsi, tagar, kategori, durasi, tautan).
- `sampul/`: gambar sampul kecil.
- Berkas video: aset Release `stok`.

Diterbitkan dengan `D:\ANIMASI\tools\terbit_reels.py` (jangan ubah manual).
